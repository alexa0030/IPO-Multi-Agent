# 比赛与简历表述建议

## 项目名称

基于多智能体协同与证据链的港股 IPO 招股书解析及财务风险识别系统

## 核心创新点

1. 将 PDF 解析、财务事实库、财务知识库、确定性指标和 Agent 推理分层，避免大模型直接阅读整本 PDF 后生成不可验证结论。
2. 三大报表保留招股书原始口径，同时用 canonical tag 支撑指标计算，实现“原文展示与计算标准化解耦”。
3. 所有事实、附注、指标和风险结论建立页码证据链，可回溯到 PDF 原页。
4. 财务解析和综合分析采用两阶段模型调用，降低上下文噪声和幻觉风险。
5. LangGraph 工作流支持后续扩展公司、业务、行业、估值、新闻和上市后预警 Agent。

## 简历 bullet

- 设计并实现港股 IPO 招股书智能财务分析系统，基于 PyMuPDF/pdfplumber 构建页级证据底稿，并通过两阶段 LLM 解析财务附注、生成可追溯财务报告。
- 构建财务报表事实库与重点财务知识库，保留原始科目口径，使用 Pydantic Schema、SQLite 和页码证据链约束模型输出。
- 使用 Python 指标引擎与可解释规则识别应收、存货、现金流、盈利能力及偿债风险，并通过 LangGraph 支持多 Agent 扩展。

## 不应夸大的部分

在没有人工审核、数据勾稽、OCR 兜底和系统化评测前，不应写“审计级准确率”“完全自动化”或“可直接替代分析师”。
