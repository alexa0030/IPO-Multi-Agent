# Architecture

## 1. Data layer

- `pages.json`: immutable page-level evidence source, containing PDF page number, full text and raw tables.
- `raw_statements.json`: original-layout primary statements and other detected main tables.
- `financial_kb.json`: structured statement facts and financial notes generated by the first LLM task.
- SQLite: persistent document, page, fact, note, metric, risk and analysis tables.

## 2. Reasoning layer

1. The first LLM task parses selected financial pages into typed JSON.
2. Python calculates deterministic metrics and applies explainable risk rules.
3. The second LLM task writes an evidence-grounded financial report.

## 3. Agent layer

The current LangGraph contains one Financial Agent. Additional agents can be inserted before `SummaryAgent`:

```text
Company Agent ─┐
Business Agent ├─> Summary Agent
Industry Agent ┤
Financial Agent┤
Market Agent ──┘
```

## 4. Traceability

Every extracted fact has a single PDF page. Every note has a page list. Every metric stores source fact IDs and source pages. Every rule finding stores source metric IDs, source fact IDs and source pages.
